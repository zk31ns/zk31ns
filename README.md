## 📌 Мои проекты

### 🔹 [Booking Seats API](https://github.com/zk31ns/booking-service-project)

**Проект представляет собой приложение, которое предоставляет API (backend) для управления бронированием мест в кафе, просмотром и предварительным заказом меню, просмотром действующих акций.**

**🎯В рамках проекта выполнены следующие задачи:**

- Разработал модуль JWT-аутентификации с access/refresh токенами (алгоритм HS256), включая валидацию сроков действия
- Реализовал ролевую систему USER/MANAGER/ADMIN с soft delete для сохранения исторических данных
- Настроил систему авторизации на Dependency Injection FastAPI, обеспечив гибкость тестирования и модульность
- Создал автоматическую документацию через Swagger/OpenAPI с примерами и схемами валидации
- Внедрил комплексную валидацию: bcrypt-хеширование паролей, нормализацию телефонов (8→+7), поддержку входа по username/email/phone
- Оптимизировал Docker-окружение для локальной разработки с изоляцией сервисов
- Работал в команде по Git Flow с код-ревью PR, реализуя защиту от SQL injection и XSS через ORM и санитизацию входных данных


**📋Функционал:**

- Управление пользователями (создание/ редактирование/ блокировка-разблокировка)
- Авторизация пользователей
- Бронирование столов в кафе с выбором даты, времени, блюд из меню
- Предоставление информации о действующих акциях
- Предоставление информации о доступных блюдах
- Управление бронированием (изменение даты, времени, меню/ отмена)
- Напоминание о бронировании (задается для каждого бронирования)
- Уведомление администратора о бронировании/ изменении бронирования


🛠️ **Технологии:**


**Основные технологии**

**Backend:**
- **Python 3.11**
- **FastAPI** + **Uvicorn** - асинхронный веб-фреймворк
- **SQLAlchemy** + **AsyncPG** - асинхронный ORM для PostgreSQL
- **Alembic** - миграции базы данных

**Безопасность:**
- **Python-JOSE** - JWT токены (HS256 алгоритм)
- **Bcrypt** - хеширование паролей
- **Pydantic** - валидация данных

**Асинхронная обработка:**
- **Celery** + **Redis** - фоновая обработка задач
- **Flower** - мониторинг Celery

**Вспомогательные:**
- **Loguru** - логирование
- **Phonenumbers** - валидация телефонов
- **Pillow** - работа с изображениями
